```text
Why repeating the same line 33 times proves nothing
Every entry describes the identical trial: same release angle, same 20-swing timing, same conclusion. A conclusion is supported by independent trials that differ in the variable being tested; repeating one measurement just adds copies of the same evidence, not new evidence.

Wording slips to watch:
- "released from the same marked angle" means amplitude was held constant, so the run cannot test the amplitude claim at all.
- "timed over twenty swings" gives the period as (total time)/20, so timing error per swing is reduced 20-fold; this improves precision but does not create a new data point.
- "changed by less than the reading error" is a comparison of two measurements against uncertainty, i.e. agreement within resolution, not proof of exact independence.
```

For small-angle motion the ideal result is
T = 2 pi sqrt(L/g)
so T is independent of amplitude only to first order; next-order correction grows roughly like theta_0^2 (order 1/16 factor).

A usable log record needs:
- the varied quantity and its values (e.g. release angles theta_0 in degrees)
- the fixed quantities (length L, mass, pivot)
- one period value per angle, with uncertainty
